# Atividade Branchs

Este repositório contém a atividade prática de **uso de branches no Git e GitHub**.

## Funcionalidades criadas
- Página Inicial (`index.html`)
- Página de Contato (`contato.html`)
- Página de Login (`login.html`)
- Página de Cadastro (`cadastro.html`)
- Estilo com CSS (`style.css`)
- Documentação (`README.md`)

## Regras seguidas
- 6 branches criadas no padrão `feature/nome-da-funcionalidade`
- Cada branch teve pelo menos 2 commits
- 3 funcionalidades foram mergeadas direto no `master`
- 3 funcionalidades foram mergeadas via Pull Request
